# GoalRepo

A multi-language developer toolbox. Small, useful CLI tools written in different programming languages.

## Tools

| Tool | Language | Description |
|------|----------|-------------|
| `go/json-fmt` | Go | JSON formatter and validator |
| `ruby/ts-conv` | Ruby | Unix timestamp converter |
| `php/b64-tool` | PHP | Base64 encode/decode utility |
| `swift/hex-color` | Swift | Color format converter |
| `kotlin/qr-gen` | Kotlin | QR code generator |
| `dart/pwd-gen` | Dart | Secure password generator |

---

Built to explore different programming languages and paradigms.
